# Submission Checklist

## Challenge Requirements

- Category: Build With Hermes Agent.
- DEV tags: `hermesagentchallenge`, `devchallenge`, `agents`.
- Language: English for prize eligibility.
- Deadline: May 31, 2026 at 11:59 PM PDT.
- One submission post per category.

## Before Publishing

- Confirm the public repository link in `dev-post.md` is correct.
- Add screenshots or a short demo video if possible:
  - Hermes cron list or run log with secrets hidden.
  - Generated `article.html` preview.
  - WeChat draft box screenshot with private account details hidden.
  - Local output folder structure.
- Confirm no secrets appear in screenshots or text.
- Confirm all private keys, AppSecrets, access tokens, media IDs, and user identifiers are redacted.
- Publish via the Build With Hermes Agent submission template on DEV.

## Optional Polish

- Record a 60-90 second video:
  - Show the problem.
  - Show Hermes scheduled jobs.
  - Run one draft generation.
  - Show the generated article package.
  - Show WeChat draft result.
- Add a small public demo repository containing sanitized scripts and setup notes.
